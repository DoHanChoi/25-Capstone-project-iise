# 피드 음악 재생 문제 분석

피드 게시물에서 재생 버튼을 누르면 `MusicPlayerBar` UI는 표시되지만 실제 오디오가 재생되지 않는다. 원인은 재생 버튼이 플레이어에 트랙을 전달하거나 재생을 시작하는 로직을 호출하지 않기 때문이다.

## 주요 발견 사항

- `src/components/post/PostCard.tsx`의 중앙 재생 버튼 핸들러는 이벤트 전파만 중단하고 `// Music play logic`이라는 주석만 있을 뿐, 음악 플레이어를 호출하거나 트랙 데이터를 로딩하지 않는다. 따라서 버튼을 클릭해도 재생이 시작되지 않는다.
- 피드에서 내려오는 `PostDto` 모델에 플레이리스트나 트랙 URL이 없어, 설령 핸들러가 실행되더라도 플레이어에 전달할 실제 오디오 소스가 없다.
- 상세 화면(`src/components/post/PostDetail.tsx`)에서 트랙을 클릭하면 `currentTrack`을 설정해 `MusicPlayerBar`를 렌더링하지만, `useMusicPlayer.playTrack` 등 오디오 엔진에 트랙 URL을 넘기는 호출을 하지 않는다. 그 결과 재생바는 메타데이터만 보여주고 실제 오디오 세션은 시작되지 않는다.

## 결론

피드 카드의 재생 경로가 구현되지 않았다. 버튼은 UI만 토글할 뿐 오디오 매니저와의 연동이 없으며, 실제 트랙 URL을 `useMusicPlayer`(또는 다른 오디오 서비스)로 전달해 재생을 시작한 뒤 `MusicPlayerBar`를 표시하도록 연결해야 한다.
